# OneLife

Personal daily-life PWA — quick capture, tasks, today view, habits. Single
user, offline-first, minimalist black-and-white UI.

See [`CLAUDE.md`](./CLAUDE.md) for the stack, commands, and non-negotiable
rules.

## Getting started

```bash
npm install
npm run dev
```

## Deploy

Push to `main` — GitHub Actions builds and publishes to GitHub Pages
automatically at `https://<github-user>.github.io/OneLife/`.
